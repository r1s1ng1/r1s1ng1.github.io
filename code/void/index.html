VOID

is currently in development

A true social platform?

The idea of Void is similar to Nostr in the fact that it is planned to be a peer to peer network but the similarities are few as full encryption along the way, locally stored posts and profile data, no relays, clientside custom content filters instead of censorship tied together by a Material 3 open sourced apk take it on a different path. As for when it will be finished and operational, if ever, is an unknown at the moment.
